### spring based hobbyWebProject ⚙
#### - STS(Spring Tool Suit)를사용해 Spring Framework, Spring JDBC, MyBatis로 DB 접근 구조를 파악하며 구현한 간단한 Restful 웹서비스입니다.
#### - MVC 패턴을 이해하고 Controller,Service,DAO,Mapper 코드를 각각 구현해보며 기존 MVC1패턴의 hobbyWebProject와의 차이점을 이해한 프로젝트입니다.

### 주요 기능 🌟
#### : 회원가입, 로그인, 아이디 중복 확인, 게시판 CRUD, 댓글 작성/삭제, 파일 업로드/다운로드, 좋아요, 조회수 구현
